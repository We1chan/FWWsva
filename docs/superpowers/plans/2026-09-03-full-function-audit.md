# 全功能与预警、GB28181 验收复核计划

目标：对照现有四项验收要求，检查可达页面操作及其后端调用，修复实质缺口，提交并推送经过验证的源码。

沿用既有设备、布控和告警架构。国标真实信令设备与历史目录演示数据分别记录；告警接口模拟验证不能替代算法产生真实事件的证据。

- [ ] 前端：核对全部可达页面和操作，重点验证筛选、导出、表单保存、布控编排、设备同步/刷新、预览和错误状态。
- [ ] 告警：回归 Analyzer 行为名称与持续时间契约，事件生命周期、图片/录像回写和查询。
- [ ] 国标：回归 WVP 完整目录校验、离线保护、媒体状态刷新和点播会话回收。
- [ ] 部署：检查当前服务，修正健康检查误判；更新安装器的已验证版本引用。
- [ ] 集成：运行前端测试/lint/生产构建、后端测试、分析器相关测试、部署测试，进行浏览器与已部署 API 冒烟。
- [ ] 交付：保存可复现证据、明确无法验证的环境条件；审查变更后分别提交并普通推送，核对远程提交。
