# GB28181 软件验收与大屏侧栏改版设计

## 目标

在不影响现有 DIRECT/RTSP 及算法输出流的前提下，本机部署完整 GB28181 协议组，优先以软件模拟器完成可重复验收，同时保留真实 IPC 或录像机的接入能力。同步将大屏左右侧的统计区域改造成更清晰、紧凑、科技感一致的数据面板。

## GB28181 架构与职责

协议组采用独立媒体平面，避免同主媒体服务混用端口、Hook 与流命名空间：

1. `easysva-wvp`：WVP 提供 SIP 注册、目录管理、INVITE/BYE 点播调度与设备在线状态，HTTP API 监听 `18080`。
2. `easysva-gb-media`：独立 ZLMediaKit 接收 WVP 调度的 PS-RTP，提供 RTSP `9997` 与浏览器代理预览 `9996`，媒体服务标识固定为 `easysva-gb28181`。
3. `easysva-gb-simulator-test6` 与 `easysva-gb-simulator-test3`：软件模拟 IPC，内部读取既有循环 RTSP 视频，但对 easySVA 完整执行 SIP 注册、目录上报、INVITE、PS-RTP 与 BYE。
4. 后端：`Gb28181SyncService` 从 WVP 分页拉取设备与通道目录，通道级幂等写入 `h_device`；`DeviceMonitorService` 按 `stream_source_type=GB28181` 发起点播，保存当前 `gb_stream_id` 与 `gb_stream_url`，并向 Analyzer 提供可拉取 RTSP 地址。
5. 前端：设备页复用“同步国标设备”“启动监控”“预览视频”入口；预览使用 nginx 对 GB 媒体的浏览器安全代理。大屏与布控页面一律优先使用 Analyzer 产出的算法 FLV，不直接向浏览器暴露 SIP/RTP。

## 部署与验收顺序

1. 安装或恢复 WVP jar、WVP 配置、`wvp` 数据库、独立 GB ZLMediaKit 配置及四个 systemd unit。
2. 写入受限权限的 `/etc/easySVA/gb28181.env`，包含数据库、SIP、ZLM 密钥和可被摄像机访问的宿主机 LAN IPv4；不得把密钥提交到仓库。
3. 启动顺序为 MariaDB/Redis → GB ZLMediaKit → WVP → 后端 → 软件模拟器；启动后执行 `easysva-gb-health`。
4. 验收软件设备在线、WVP 目录、后端同步、点播 RTSP、浏览器 FLV、Analyzer 检测输出以及停止点播后的资源回收。
5. 真实 IPC 接入只替换设备的 SIP server、域、账号和密码；端口放行 SIP TCP/UDP 5060、RTP 10000 UDP、40002–45000 TCP/UDP、GB RTSP 9997 TCP 与浏览器代理 9996 TCP。真实设备验收前需确认 NAT、公网映射和防火墙策略。

## 失败处理

- WVP 目录拉取失败不得把既有 GB 通道误标记为离线；同步在获取完整快照前不写库。
- 点播失败需返回设备、通道和 WVP 原始错误摘要；前端显示可操作提示，不能降级为伪造“在线”。
- GB 专用服务失效不会影响已有 `source/live/analyzer` 直连流；后端定时同步应节流记录错误。
- 软件模拟器不可用时，验收明确失败，不以 RTSP 直连替代为“GB28181 通过”。

## 大屏视觉与数据设计

整体采用“深海蓝数据舱”风格：深色渐变底、细密网格、低亮度面板玻璃层、青蓝信息高亮与橙色告警点缀。避免重型装饰图标占据数据空间，优先保证远距离读数。

### 左侧

- **监测点**：三个紧凑状态指标（总数、在线、离线），用环形进度与状态色表达，不再使用三个重复的大型仪表。
- **处置情况**：环图中心显示处置率，图例同时显示数量与占比；未处理为橙色、误报为紫灰、已处理为青色，保证语义稳定。

### 右侧

- **综合统计**：年度、当月、已处置报警改为同尺寸数字卡，包含状态标记与跳转语义。
- **报警统计**：柱状排名图改为横向排行条，长组织名称可读，附带总数和当前排名。
- **报警增长率**：六个指标按“增长 / 处置”两列、月/季/年三行编排，正负趋势颜色和箭头遵从统一规则。

### 可用性与适配

- 所有颜色至少搭配文字和图形，不能只依赖颜色表达状态。
- 遵从 `prefers-reduced-motion`；仅保留加载渐显和小范围光扫动画。
- 继续基于 1920×1080 缩放容器，避免新增固定像素溢出。
- 现有接口与路由不变：`getDeviceNum`、`getLevelSpread`、`getRanking`、`getGrowth`、`getMonthWaring` 继续提供数据。

## 验证

- 运行部署脚本及 GB 安装/健康回归测试。
- 用浏览器自动化登录大屏，验证左右组件渲染、无控制台错误、数据请求成功、缩放下无溢出。
- 验证四路既有算法输出和 GB 软件模拟器产生的布控输出流均可连续读取。
- 对会改变业务状态的真实点播、停止与删除动作采用受控单设备验收，保留日志证据。
