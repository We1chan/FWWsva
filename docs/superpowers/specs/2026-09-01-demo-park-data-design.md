# 园区安防演示数据设计

## 目标

让 easySVA 的首页、设备管理、布控管理和报警管理呈现可信且可操作的园区安防演示场景，同时保留现有的验收用模拟摄像头与 YOLO 人员检测链路。

## 范围

- 新增 6 个以“演示-”开头的园区摄像头设备：园区入口、停车场、办公楼大厅、仓库通道、周界东侧、消防通道。
- 其中 3 个设备连接到本机可用的模拟 RTSP 视频流并可在网页预览；其余 3 个以离线或维护状态展示。
- 新增多条近期告警，覆盖人员停留、区域入侵、越界和安全帽识别等类型，并包含未处理、处理中、已确认和误报状态。
- 新增与在线设备关联的布控任务，使布控列表和统计信息有完整内容。
- 告警视频与图片仅引用本地现有可访问的演示媒体；不能生成失效 URL 或伪造外部摄像头连接。

## 数据约束

- 所有新增记录均带“演示-”前缀或演示说明，便于筛选和后续清理。
- 不修改既有验收任务、真实业务记录、账号、权限或系统配置。
- 通过系统既有数据结构和服务接口/数据库约束写入，保证列表、详情和统计查询正常。
- 写入前记录受影响表中演示前的数据量；写入后核对新增量和网页可见性。

## 验证

1. 设备列表展示 6 个演示设备，至少 3 个可播放预览。
2. 布控列表展示演示任务及不同运行状态。
3. 报警页面可按时间看到近期演示告警，状态与类型分布合理。
4. 首页统计、最新告警和告警图片区域不出现错误或失效媒体。
5. 现有“模拟RTSP摄像头”和“验收点1-YOLO模拟检测”保持可用。

## 清理方式

后续可按“演示-”前缀及本次记录的演示标记筛选删除；清理仅删除本次新建记录及其关联的演示告警/任务，不触及原有验收数据。
