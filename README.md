# easySVA

#### 介绍
easySVA（easy Surveillance Video Analytics）是一款面向中小企业的轻量化分布式 AI 视频分析系统。项目基于若依前后端分离框架开发，AI 分析器采用 C++ 实现，允许大模型对告警结果进行复核。整体架构清晰、代码简洁规范，非常适合零基础及初学者入门学习视频分析相关技术。

#### 安装教程

下载install_source.sh脚本
会自动安装环境同时下载源代码进行编译
把install_source.sh和easySVA-lib.zip拷贝到/opt目录下
easySVA-lib.zip包含了cuda、onnxruntime、ffmepg、opencv等所需代码，
请提前下载，并和install_source.sh放在/opt目录下
然后以root身份执行脚本就可以了
